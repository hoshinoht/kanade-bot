# Chat guide

- `persona/`, `prompts/`: persona bundles and code-owned policy prompts (own contracts in `docs/v5/`).
- `gate/`: the pure answer/refuse decision (v4 `chat/gate.py`): refusal order, pilot channel allow-list (`PilotSettings`, `ChannelDirectory`, threads count as their parent), resolved mentions only, the per-person and guild-pool `RateLimiter` (monotonic seconds passed in; both read before either is spent; admins exempt), `is_bot_admin`, `retry_note`. Every refusal except a spent budget is silent.
- `authority/`: `require_authority`, the single boundary for cards about existing runs and weekly timings; enforced by the dispatcher whatever was offered.
- `tools/`: `schemas/` (verbatim v4 compact JSON per tool, never reformat; `request_tools` is v5), `read/` (pure read tools and shared helpers over a caller-loaded `ToolWorld` and `ToolContext::now`), `propose/` (proposal tools; stage only through `SchedulerService::propose`, then supersede like v4 `_record`; never write schedule rows or post cards; `when.rs` is the bounded `parse_when`), `bundles/` (dynamic tool loading: fixed bundle order READ → `request_tools` → STRATEGY → RUN_WRITES → FIXED_WRITES, code-only routing, one `request_tools` per question; `ToolOffer::full_set` is v4's surface byte for byte), `dispatch/` (the non-failing boundary: identity decode of arguments, read-only → unknown → unoffered refusals in that order, identity encode of every result).
- `sanitize/`: forged-note defusing, member-facing scrubbing, false-claim stripping, trusted schedule defaults, tidy bounds and schedule regrounding (v4 `agent.py` helpers). v4 lookarounds are emulated explicitly; keep them that way (`regex` has none).
- Named v5 differences: `D-PROPOSE-REFUSES` (unworkable proposals refused up front, no card), dynamic tools (vectors replay in full-set mode), `D-TOOL-ROUNDS` (8 by default), K-WHEN-SUBSET (no `dateparser`), cards are posted by the caller (tools hand over `ProposalCard`s). Personal memory is removed; do not add it.
- Loop and context assembly (rounds, history, reply chains, budgets) are slice C2, not here.
- Check: `cargo test --all-features --test chat` (vectors in `docs/v5/vectors/chat/`; `loop`/`context` are C2's).
