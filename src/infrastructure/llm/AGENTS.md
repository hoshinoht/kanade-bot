# LLM provider guide

- Every model call goes through `execution::CompletionRunner` over the `LlmProvider` trait (`provider.rs`); service code never talks HTTP or a vendor client directly, and there is no native Ollama client.
- `execution/`: runner, retry/deadline `policy.rs`, encoded-byte and token `accounting.rs`, request/response validation, schema check and quarantine of malformed output. `capabilities/`: per-model capabilities from Kanata `/v1/models` metadata (`listing.rs`), operator declarations or a minimal profile; `downgrade.rs` remembers rejected fields per alias. `shaping.rs` sends only supported fields and embeds the schema instruction when structured output is unsupported. `wire/`: OpenAI JSON types. `http/`: `OpenAiCompatibleProvider` (`config.rs`, `endpoint.rs`, `transport.rs`). `fake.rs`: test-support fake.
- `governor/`: model traffic governor (`config` groups/roles/policy, priority permit `pool`, token-bucket `rate`, retry `budget`, per-group `breaker`, `snapshot` for the Limits DTO, injected `jitter`). Pure state takes `now`; waits use tokio time; no wall-clock reads. Check: `cargo test --all-features --test governor`.
- Invariants: capabilities resolved once per runner call and passed via `complete_with`; at most one reshaped retry after a capability rejection; transient-only retries; listing fetch bounded (5 s or half the remaining deadline), cached 300 s, negatively cached 30 s, single-flight.
- HTTP: https with verified roots (webpki-roots or custom); plain http only for loopback IPs, `localhost` (must resolve to loopback) and `host.docker.internal`; no redirects; bodies capped (1 MiB completions, 256 KiB listings, 64 KiB errors); bearer key from caller bytes, redacted in `Debug`/errors.
- Env/config-file wiring and live Kanata verification are deferred to the Kanata integration step; tests use loopback stubs and the TLS fixtures in `tests/fixtures/provider/`.
- Contract: `docs/v5/provider-contract.md` (update it with behaviour changes). Check: `cargo test --all-features --test provider_contract`.
