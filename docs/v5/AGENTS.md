# v5 docs guide

- Contracts (keep in sync with the code they describe): `provider-contract.md` (`src/infrastructure/llm`), `discord-adapter.md` (`src/bot`), `maintenance-contract.md` (store ownership, backups, delivery journal), `runtime-bootstrap.md` (binary commands and env), `v4-import.md` (`kanade import v4`, the testing import from a v4 snapshot; `src/import/v4`), `history.md` (change history, drafts, requests, preconditions, cherry-pick), `attendance.md` (answer states, standing answers, attendance; `src/domain/attendance`), `extraction-orchestration.md` (debounce, backlog, governed extraction calls, log outcomes, rescan jobs; `src/extract/{pipeline,backlog.rs,rescan}`), `chat-orchestration.md` (chat context, the governed question loop, clean retry, cards, chat log; `src/chat/{context,answer}`), `oauth-security.md` (Discord OAuth checklist gating admin login and public exposure), `admin-api.md` and `limits-contract.md` (PWA-facing contracts, proposed until the JSON API lands).
- Decisions and evidence: `compatibility.md` + `inventory.json` (v4 surface dispositions), `stack-evaluation.md` + `stack-evidence/` (captured probes, audits, licences), `design/` (the current admin PWA design spec: start at `design/README.md`; keep it as-built and add new user design decisions there), `pwa-design-guidelines.md` (superseded by `design/`, kept as history), `m3-expressive-evaluation.md` (proposal: what to adopt from Material 3 Expressive) + `m3-expressive-verification.md` (M3 values and sources checked against the live site), `maplestory-openapi-evaluation.md` (proposal: Nexon Open API + MapleScouter for MapleSEA), `legacy-relocation.md`. Private plans, reviews and dev notes (e.g. `m3e-rail-design-spec.md`, `public-portal-plan.md`, boss strategy reviews) live in the git-ignored `docs/notes/`, not here.
- `vectors/` are frozen Python-oracle outputs: `domain/`, `scheduler/` (scheduler, reminders, mutations, dispatch, mentions, digest families), `persona/`, `extract/`, `chat/`, each with schemas and an `index.json`. Never hand-edit expected values; change the generator under `legacy/python/scripts/v5_vectors/` and regenerate.
- Regenerate or check from `legacy/python/`: `uv run python -m scripts.v5_vectors [--check]`, `uv run python -m scripts.v5_vectors.scheduler [--check]`, `uv run python -m scripts.v5_vectors.persona [--check]`, `uv run python -m scripts.v5_vectors.extract [--check]`, `uv run python -m scripts.v5_vectors.chat [--check]`. Existing families must stay byte-identical unless the change is intended.
- Inventory: from `legacy/python/`, `uv run python ../../scripts/check_v5_inventory.py` validates `inventory.json` against the v4 source; its tests are `uv run pytest -q ../../scripts/v5_inventory/test_validation.py`.
